## 1. VO de domínio: `SearchFilterTree`

### Contexto

Hoje o `FilterBuilder` recebe um `dict` solto. Isso funciona, mas não há nenhum VO garantindo que esse formato é estável e compartilhável entre CLI, FastAPI e frontend.

### Problema

Sem um VO, cada camada pode inventar o próprio formato, e você perde o controle do contrato. O `FilterBuilder` vira um detalhe “mágico” no domínio.

### Solução esperada

Criar um VO imutável que encapsula o `dict` da árvore, com métodos mínimos:

* `from_raw(...)` para aceitar `dict` ou o próprio VO.
* `to_dict()` para entregar o formato que o `FilterBuilder` espera.
* `is_empty()` para curto-circuitar.

### Implementação

Crie `domain/value_objects/search_filter_tree.py`:

```python
# domain/value_objects/search_filter_tree.py
from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Dict, Optional


FilterDict = Dict[str, Any]


@dataclass(frozen=True)
class SearchFilterTree:
    """
    VO genérico para a árvore de filtros consumida pelo FilterBuilder.

    A estrutura interna `raw` deve respeitar o contrato do FilterBuilder, por ex.:

        {
            "and": [
                {"status": "ATIVO"},
                {
                    "or": [
                        {"has_bdr": True},
                        {"market": {"in": ["NM"]}}
                    ]
                },
                {"market": {"in": ["NM", "N2"]}}
            ]
        }

    Raiz: "and" / "or" / "not" OU um dict de campo -> condição.
    Folha: valor direto ou dict de operadores (==, !=, >, <, in, contains, etc.).
    """

    raw: FilterDict

    @classmethod
    def from_raw(cls, data: Optional[Any]) -> Optional["SearchFilterTree"]:
        """Converte dict/VO em SearchFilterTree, ou None se não houver filtro."""
        if data is None:
            return None
        if isinstance(data, SearchFilterTree):
            return data
        if not isinstance(data, dict):
            raise TypeError(
                f"SearchFilterTree.from_raw espera dict ou SearchFilterTree, "
                f"recebeu {type(data)}"
            )
        return cls(raw=data)

    def to_dict(self) -> FilterDict:
        """Retorna o dict no formato esperado pelo FilterBuilder."""
        return self.raw

    def is_empty(self) -> bool:
        """True quando não há nenhuma condição na árvore."""
        return not bool(self.raw)
```

## 3. DTO Pydantic: `SearchFiltersDTO` (camada de apresentação / FastAPI)

### Contexto

Os endpoints FastAPI precisam receber filtros JSON no mesmo formato que o CLI já usa, mas com validação mínima e conversão para o VO de domínio.

### Problema

Hoje não existe nenhum DTO que represente o “filtro genérico”. Quando for criar endpoints que aceitam filtros, cada rota vai inventar o próprio `dict`.

### Solução esperada

* Criar um DTO Pydantic que encapsula a árvore (`tree`).
* Ter um método `to_domain()` que devolve `SearchFilterTree`.
* Manter o formato compatível com o `FilterBuilder` (chaves `and`, `or`, `not`, campos, operadores).

### Implementação

Crie `presentation/backend/dto/search_filters_dto.py`:

```python
# presentation/backend/dto/search_filters_dto.py
from __future__ import annotations

from typing import Any, Dict, Optional

from pydantic import BaseModel, Field

from domain.value_objects.search_filter_tree import SearchFilterTree


class SearchFiltersDTO(BaseModel):
    """
    DTO genérico de filtros estruturados.

    `tree` deve seguir o contrato aceito por FilterBuilder, por exemplo:

        {
            "and": [
                {"status": "ATIVO"},
                {
                    "or": [
                        {"has_bdr": True},
                        {"market": {"in": ["NM"]}}
                    ]
                },
                {"market": {"in": ["NM", "N2"]}}
            ]
        }
    """

    tree: Optional[Dict[str, Any]] = Field(default=None)

    def to_domain(self) -> Optional[SearchFilterTree]:
        """Converte o DTO em VO de domínio."""
        return SearchFilterTree.from_raw(self.tree)
```

```python
from __future__ import annotations

from typing import Any, Dict


FilterDict = Dict[str, Any]


def build_ratios_filter_by_issuing_company(issuing_company: str) -> FilterDict:
    """
    Filtro básico para ratios por empresa emissora.

    Equivalente a:
        issuing_company == <issuing_company> (case insensitive opcional).
    """
    return {
        "and": [
            {
                "issuing_company": {
                    "==": issuing_company,
                    "case": False,
                }
            }
        ]
    }


def build_default_ratios_filter() -> FilterDict:
    """
    Ponto de extensão para um filtro padrão mais complexo.

    Exemplo (comentado) de filtro composto que o FilterBuilder entende:

        return {
            "and": [
                {"status": "ATIVO"},
                {
                    "or": [
                        {

                },
```

```python
from application.usecases.normalize_ratios import (
    get_company_ratios_frame_from_snapshot,
    _load_indicators,

@dataclass(frozen=True)
class GetCompanyRatiosFrameRequest:
    company_name: str
    filters: SearchFilterTree | None = None


@dataclass
class GetCompanyRatiosFrameUseCase:
    """
    Caso de uso de leitura de ratios para UMA empresa.

    Não conhece FastAPI, Plotly nem Vue.
    Só entrega CompanyRatiosFrameDTO.

    config: ConfigPort
    logger: LoggerPort

    repository_indicators: RepositoryIndicatorsPort
    repository_statements_fetched: RepositoryStatementsFetchedPort
    cache_ratios: CacheRatiosPort

        return self.run(request=request)

    def run(self, request: GetCompanyRatiosFrameRequest) -> CompanyRatiosFrameDTO:
        # 1. Carregar indicadores tratados (como no NormalizeUseCase)
        with self.uow_factory() as uow:
            treated_indicators = _load_indicators(
                repository_indicators=self.repository_indicators,
                uow=uow,
            )

        # 2. Delegar para helper snapshot → cache → df

            config=self.config,
            logger=self.logger,

            treated_indicators=treated_indicators,
            repository_stock_quote=self.repository_stock_quote,
            repository_statements_fetched=self.repository_statements_fetched,
            uow_factory=self.uow_factory,
            filters=request.filters,
        )

        return result
```

```python
# application/dtos/account_series_dto.py
from __future__ import annotations

from dataclasses import dataclass
from datetime import date, datetime
from typing import List, Optional, Union


DateLike = Union[date, datetime]


@dataclass(frozen=True)
class AccountSeriesPointDTO:
    """
    Um ponto de uma série temporal de conta/ratio.

    'date' é o eixo temporal.
    'value' é o valor numérico (pode ser None para buracos na série).
    """
    date: DateLike
    value: Optional[float]


@dataclass(frozen=True)
class AccountSeriesDTO:
    """
    Série temporal de um account (ratio, KPI etc.) para uma empresa/ticker.
    """
    ticker: Optional[str]
    account_code: str   # ex: "02.03", "ROE"
    label: str          # ex: "Patrimônio Líquido"
    points: List[AccountSeriesPointDTO]
```

Pontos importantes:

* Tipos simples, sem Pydantic.
* Nomes `date` e `value` são semânticos de domínio.

```python
@dataclass
class GetCompanyAccountsChartUseCase:
    """
    Caso de uso: obter séries de accounts (ratios) por empresa.

    Entrada: company_name, accounts desejadas, filtros.
    Saída: CompanyAccountsSeriesDTO, agnóstico a Plotly/FastAPI.
    """
    ratios_frame_usecase: GetCompanyRatiosFrameUseCase
    account_labels: dict[str, str] | None = None  # opcional

    def __call__(
        self,
        *,
        company_name: str,
        accounts: Sequence[str],
        filters: Optional[SearchFilterTree] = None,
    ) -> CompanyAccountsSeriesDTO:
        # 1. Validar entrada
        company_name = (company_name or "").strip()
        if not company_name:
            raise DomainError(
                "company_name é obrigatório para obter séries de accounts."
            )

        account_codes = [str(a).strip() for a in (accounts or []) if str(a).strip()]
        if not account_codes:
            raise DomainError(
                "Lista de accounts não pode ser vazia ao solicitar séries de gráfico."
            )

        # 2. Obter frame de ratios via Bloco 2
        ratios_frame_dto: CompanyRatiosFrameDTO = self.ratios_frame_usecase(
            company_name=company_name,
            filters=filters,
        )
        df = ratios_frame_dto.frame

        if df is None or df.empty:
            raise DomainError(
                f"Nenhum dado de ratios disponível para empresa "
                f"'{ratios_frame_dto.company_name}'."
            )

        # 3. Garantir índice temporal ordenado
        df = self._ensure_datetime_index(df)

        # 4. Selecionar colunas pedidas
        df_selected = self._select_accounts(df, account_codes, ratios_frame_dto)

        # 5. Converter DataFrame em séries de domínio
        series_dtos = self._build_series_dtos(
            company_name=ratios_frame_dto.company_name,
            ticker=ratios_frame_dto.ticker,
            df=df_selected,
        )

        # 6. Empacotar em CompanyAccountsSeriesDTO
        return CompanyAccountsSeriesDTO(
            company_name=ratios_frame_dto.company_name,
            ticker=ratios_frame_dto.ticker,
            series=series_dtos,
            meta={**ratios_frame_dto.meta},
        )
```

Helpers internos:

```python
    def _ensure_datetime_index(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Garante que o índice do DataFrame é temporal e ordenado.
        Tenta converter índice atual ou coluna 'date'.
        """
        index = df.index

        if not isinstance(index, (pd.DatetimeIndex, pd.PeriodIndex)):
            df = df.copy()
            if "date" in df.columns:
                df["date"] = pd.to_datetime(df["date"], errors="coerce")
                df = df.set_index("date")
            else:
                df.index = pd.to_datetime(df.index, errors="coerce")

        df = df.sort_index()
        return df

    def _select_accounts(
        self,
        df: pd.DataFrame,
        account_codes: Sequence[str],
        ratios_frame_dto: CompanyRatiosFrameDTO,
    ) -> pd.DataFrame:
        """
        Seleciona somente as colunas pedidas.
        Se alguma estiver ausente, levanta DomainError com detalhe.
        """
        missing = [c for c in account_codes if c not in df.columns]
        if missing:
            raise DomainError(
                f"As seguintes accounts não existem no DataFrame de ratios "
                f"para '{ratios_frame_dto.company_name}': {missing}. "
                f"Colunas disponíveis: {list(df.columns)}"
            )

        df_selected = df[account_codes].sort_index()
        return df_selected
```

Conversão para séries:

```python
    def _build_series_dtos(
        self,
        *,
        company_name: str,
        ticker: str | None,
        df: pd.DataFrame,
    ) -> List[AccountSeriesDTO]:
        """
        DataFrame (index temporal, colunas numéricas) -> List[AccountSeriesDTO].
        """
        series: List[AccountSeriesDTO] = []

        if df.empty:
            return series

        labels_map = self._get_account_labels(df.columns)

        for account_code in df.columns:
            col = df[account_code]

            # opcional: filtrar NaN para reduzir ruído
            # col = col.dropna()

            points: List[AccountSeriesPointDTO] = []

            for idx, value in col.items():
                # idx é Timestamp ou date; value pode ser NaN
                if pd.isna(value):
                    point_value = None
                else:
                    point_value = float(value)

                if hasattr(idx, "date"):
                    d: date = idx.date()
                else:
                    d = idx

                points.append(
                    AccountSeriesPointDTO(
                        date=d,
                        value=point_value,
                    )
                )

            label = labels_map.get(account_code, account_code)

            series.append(
                AccountSeriesDTO(
                    ticker=ticker or company_name,
                    account_code=account_code,
                    label=label,
                    points=points,
                )
            )

        return series

    def _get_account_labels(self, account_codes: Iterable[str]) -> dict[str, str]:
        """
        Hook para mapear códigos de account para labels amigáveis.

        Hoje: usa account_labels injetado, se existir.
        Senão: usa o próprio código.
        """
        if self.account_labels:
            return {
                code: self.account_labels.get(code, code)
                for code in account_codes
            }
        return {code: code for code in account_codes}
```

Com isso:

* Entrada inválida gera `DomainError` com mensagem clara.
* Se accounts pedidas não existem, o erro lista `missing` e colunas disponíveis.
* Index é garantido como temporal e ordenado.
* Cada coluna vira uma `AccountSeriesDTO` consistente.

```python
from typing import List

from application.dtos.company_accounts_series_dto import CompanyAccountsSeriesDTO
from presentation.backend.dto.chart_dto import ChartDTO, PlotlyTraceDTO


def company_accounts_to_chart(dto: CompanyAccountsSeriesDTO) -> ChartDTO:
    """
    Converte CompanyAccountsSeriesDTO em ChartDTO genérico para Plotly.
    """
    traces: List[PlotlyTraceDTO] = []

    for series in dto.series:
        x = [p.date for p in series.points]
        y = [p.value for p in series.points]

        traces.append(
            PlotlyTraceDTO(
                x=x,
                y=y,
                type="scatter",
                name=f"{series.account_code} - {series.label}",
                # se PlotlyTraceDTO tiver 'meta' ou 'customdata', você pode incluir:
                # meta={"ticker": series.ticker}
            )
        )

    layout = {
        "title": f"Séries de contas – {dto.company_name}",
        "xaxis": {"title": "Data"},
        "yaxis": {"title": "Valor"},
    }

    return ChartDTO(
        data=traces,
        layout=layout,
        # se ChartDTO tiver meta, você pode passar dto.meta aqui
        # meta=dto.meta,
    )
```

```python
# presentation/backend/routers/ratios_charts.py
from __future__ import annotations

from typing import List, Optional

from fastapi import APIRouter, Depends, HTTPException, status

from application.usecases.get_company_accounts_chart import (
    GetCompanyAccountsChartUseCase,
)
from domain.value_objects.search_filter_tree import SearchFilterTree

from presentation.backend.dependencies.ratios_chart_dependencies import (
    get_company_accounts_chart_usecase,
)
from presentation.backend.dto.chart_dto import ChartDTO, PlotlyTraceDTO
from presentation.backend.dto.company_accounts_chart_request_dto import (
    CompanyAccountsChartRequestDTO,
)
from presentation.backend.dto.search_filters_dto import SearchFiltersDTO


router = APIRouter(
    prefix="/api/charts/ratios",
    tags=["charts-ratios"],
)


def _map_filters_dto_to_vo(
    filters_dto: Optional[SearchFiltersDTO],
) -> Optional[SearchFilterTree]:
    """
    Único ponto que conhece Pydantic + VO de domínio.
    """
    if filters_dto is None or filters_dto.tree is None:
        return None
    return SearchFilterTree(tree=filters_dto.tree)


@router.post(
    "/company",
    response_model=ChartDTO,
)
async def get_company_ratios_chart(
    payload: CompanyAccountsChartRequestDTO,
    usecase: GetCompanyAccountsChartUseCase = Depends(
        get_company_accounts_chart_usecase
    ),
) -> ChartDTO:
    """
    Endpoint fino: recebe company_name, accounts e filters,
    chama o caso de uso de ratios e converte o resultado em ChartDTO.
    """
    filter_tree = _map_filters_dto_to_vo(payload.filters)

    result = usecase(
        company_name=payload.company_name,
        accounts=payload.accounts,
        filters=filter_tree,
    )
    # result deve ser um CompanyAccountsSeriesDTO
    # com atributos: company_name, series, cache_info

    if not result.series:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Nenhuma série encontrada para empresa '{payload.company_name}'",
        )

    traces: List[PlotlyTraceDTO] = []
    for series in result.series:
        x = [point.date for point in series.points]
        y = [point.value for point in series.points]

        trace = PlotlyTraceDTO(
            x=x,
            y=y,
            type="scatter",
            mode="lines",
            name=f"{series.account_code} - {series.label}",
            extra={
                "hovertemplate": "%{x}<br>Valor: %{y}<extra></extra>",
            },
        )
        traces.append(trace)

    layout = {
        "title": f"Ratios – {result.company_name}",
        "xaxis": {"title": "Data"},
        "yaxis": {"title": "Valor"},
    }

    meta = {
        "company_name": result.company_name,
        "cache_hit": getattr(result.cache_info, "hit", None),
        "cache_key": getattr(result.cache_info, "cache_key", None),
    }

    return ChartDTO(
        data=traces,
        layout=layout,
        meta=meta,
    )
```

Para isso funcionar, o `CompanyAccountsSeriesDTO` na camada de aplicação deve expor:

* `company_name: str`
* `series: list[AccountSeriesDTO]`
* `cache_info` com pelo menos `hit` e `cache_key` ou algo equivalente.

Se ainda não expõe, o júnior precisa ajustar o DTO de aplicação.

```js
export async function fetchCompanyRatiosChart(companyName, accounts, filterTree = null) {
  const name = String(companyName || "").trim();
  if (!name) {
    throw new Error("Nome de companhia inválido para carregar gráficos de cuentas");
  }
```

## 5.2 – Store Pinia com ChartDTO único e filtros

**Contexto**

A store precisa ser a fonte de verdade para:

* empresa selecionada
* accounts selecionados
* filtro em árvore (`filterTree`)
* um único `ChartDTO` com múltiplas séries
* estados de loading e erro

**Objetivo**

Uma action `loadChart()` faz uma chamada ao backend e atualiza `chart` único.
O componente de visualização apenas consome esse `ChartDTO`.

**Implementação**

Arquivo: `presentation/frontend/src/store/accountChartsStore.js`

```js
import { defineStore } from "pinia";
import { fetchCompanyRatiosChart } from "@/services/apiService";
import { buildChartFilterTree } from "@/utils/chartFilters";

export const useAccountChartsStore = defineStore("accountCharts", {
  state: () => ({
    companyName: "",          // nome da empresa
    selectedAccounts: [],     // lista de códigos ["02.03", "03.01"]
    filterTree: null,         // árvore de filtros compatível com backend
    chart: null,              // ChartDTO único com múltiplas séries
    isLoading: false,
    error: null,
  }),

  actions: {
    setCompanyName(name) {
      this.companyName = String(name || "").trim();
    },

    setSelectedAccounts(accounts) {
      this.selectedAccounts = Array.isArray(accounts)
        ? accounts.map(code => String(code || "").trim()).filter(Boolean)
        : [];
    },

    // recebe filterQuery do companyStore e converte em árvore
    setFilterFromFilterQuery(filterQuery) {
      this.filterTree = buildChartFilterTree(filterQuery);
    },

    resetChart() {
      this.chart = null;
      this.error = null;
    },

    async loadChart() {
      if (!this.companyName) {
        this.error = "Selecione uma companhia antes de carregar o gráfico";
        this.chart = null;
        return;
      }

      if (!this.selectedAccounts.length) {
        this.error = "Selecione pelo menos uma conta para exibir";
        this.chart = null;
        return;
      }

      this.isLoading = true;
      this.error = null;

      try {
        const dto = await fetchCompanyRatiosChart(
          this.companyName,
          this.selectedAccounts,
          this.filterTree,
        );

        // dto é o ChartDTO com múltiplas séries
        this.chart = dto;
      } catch (err) {
        console.error(err);
        const message =
          err?.response?.data?.detail ||
          err?.message ||
          "Erro ao carregar gráfico de ratios";

        this.error = message;
        this.chart = null;
      } finally {
        this.isLoading = false;
      }
    },
  },
});
```

Essa store assume:

* `buildChartFilterTree` traduz a DSL de filtros da tela de busca para a árvore que o backend entende.
* O backend já devolve `ChartDTO.data` contendo uma trace por account.

## 5.4 – Builder de filtros em árvore compatível com `FilterBuilder` e `SearchFilterTree`

**Contexto**

O backend usa um `FilterBuilder` sobre um `SearchFilterTree` em forma de dicionário.
O `companyStore` já produz uma DSL estruturada:

```js
filterQuery = {
  clauses: [
    {
      logical: "AND",
      condition: {
        field: "market",
        operator: "IN",
        values: ["NM", "N2"],
      },
    },
    {
      logical: "OR",
      condition: {
        field: "status",
        operator: "EQUALS",
        values: ["ATIVO"],
      },
    },
    // e assim por diante
  ],
};
```

Você precisa converter isso em algo como:

```js
{
  and: [
    { market: { in: ["NM", "N2"] } },
    { status: "ATIVO" }
  ]
}
```

Ou combinações mais complexas com `or` e `not`.

**Implementação**

Arquivo novo: `presentation/frontend/src/utils/chartFilters.js`

```js
// mapeia operadores da DSL do frontend para nomes esperados pelo backend
const OPERATOR_TO_FILTER_BUILDER = {
  IN: "in",
  EQUALS: "eq",
  CONTAINS: "contains",
  STARTS_WITH: "startswith",
  BETWEEN: "between",
  GT: "gt",
  GTE: "gte",
  LT: "lt",
  LTE: "lte",
};

/**
 * Constrói uma folha: { field: { op: value } } ou { field: value }
 */
function buildLeafFromCondition(condition) {
  if (!condition || !condition.field) {
    return null;
  }

  const field = condition.field;
  const operator = String(condition.operator || "").toUpperCase();
  const values = Array.isArray(condition.values) ? condition.values : [];

  const cleanedValues = values
    .map(v => (v === null || v === undefined ? "" : String(v).trim()))
    .filter(v => v.length);

  if (!cleanedValues.length) {
    return null;
  }

  const fbOp = OPERATOR_TO_FILTER_BUILDER[operator] || null;

  // igualdade simples com um valor
  if (fbOp === "eq" && cleanedValues.length === 1) {
    return {
      [field]: cleanedValues[0],
    };
  }

  // IN ou EQUALS com múltiplos valores
  if ((fbOp === "in" || fbOp === "eq") && cleanedValues.length > 1) {
    return {
      [field]: {
        in: cleanedValues,
      },
    };
  }

  // BETWEEN com dois limites
  if (fbOp === "between" && cleanedValues.length === 2) {
    return {
      [field]: {
        between: cleanedValues,
      },
    };
  }

  // operadores relacionais
  if (["gt", "gte", "lt", "lte"].includes(fbOp)) {
    return {
      [field]: {
        [fbOp]: cleanedValues.length === 1 ? cleanedValues[0] : cleanedValues,
      },
    };
  }

  // CONTAINS, STARTS_WITH e similares
  if (fbOp && !["eq", "in", "between"].includes(fbOp)) {
    return {
      [field]: {
        [fbOp]: cleanedValues.length === 1 ? cleanedValues[0] : cleanedValues,
      },
    };
  }

  // fallback: igualdade simples com primeiro valor
  return {
    [field]: cleanedValues[0],
  };
}

/**
 * Constrói árvore de filtros a partir de filterQuery.clauses
 */
export function buildChartFilterTree(filterQuery) {
  if (!filterQuery || !Array.isArray(filterQuery.clauses)) {
    return null;
  }

  const andClauses = [];
  const orClauses = [];
  const notClauses = [];

  for (const clause of filterQuery.clauses) {
    if (!clause || !clause.condition) continue;

    const leaf = buildLeafFromCondition(clause.condition);
    if (!leaf) continue;

    const logical = String(clause.logical || "AND").toUpperCase();

    if (logical === "AND") {
      andClauses.push(leaf);
    } else if (logical === "OR") {
      orClauses.push(leaf);
    } else if (logical === "NOT") {
      notClauses.push({ not: leaf });
    }
  }

  let tree = null;

  // monta nó com AND
  if (andClauses.length === 1) {
    tree = andClauses[0];
  } else if (andClauses.length > 1) {
    tree = { and: andClauses };
  }

  // integra OR
  if (orClauses.length === 1) {
    const orNode = orClauses[0];
    tree = tree ? { and: [tree, orNode] } : orNode;
  } else if (orClauses.length > 1) {
    const orNode = { or: orClauses };
    tree = tree ? { and: [tree, orNode] } : orNode;
  }

  // integra NOT
  if (notClauses.length === 1) {
    const notNode = notClauses[0];
    tree = tree ? { and: [tree, notNode] } : notNode;
  } else if (notClauses.length > 1) {
    const notNode = { and: notClauses };
    tree = tree ? { and: [tree, notNode] } : notNode;
  }

  return tree;
}
```

Uso na store (já mostrado, mas explícito):

```js

  this.filterTree = buildChartFilterTree(filterQuery);
}
```

Com isso:

* A DSL de filtros do frontend é traduzida de forma sistemática para `SearchFilterTree`
* O mesmo formato será entendido pelo `FilterBuilder` no domínio
* CLI e FastAPI podem compartilhar a mesma “linguagem de filtros”
